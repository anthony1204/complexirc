# Complex IRC
a mod that adds irc support into the chat, complete with chat channels.

[modrith link](https://modrinth.com/mod/complex-irc)

### usage:
use the mod-menu mod to open the mod's config, where you can set server ip, username and the channel.
this mod is intended for 1 irc channel only

there are 3 buttons on top of the chat input bar when you open chat
- minecraft
- global
- irc

these are the chat channels

if you have minecraft chat selected, only minecraft chat will be shown, without irc.

global is both channels (shows messages from both), irc chat will only show irc messages and ignore player chatting (you can view by switching to minecraft/global at any time)

irc chat will allow server messages to be shown, such as announcements/notifications (everything but player chat is shown with irc channel)

### commands:
- /irc connect - connects you to irc (you will autoconnect when you click the 'irc' button on your chat bar also)
- /irc disconnect - disconnects you from irc
- /irc raw - for advanced users; sends a raw command to the irc instance

### tips:
- prefixing your messages with '!' will force them to minecraft chat
- same with prefixing your messages with '#' but they will be sent to irc
- sending just '!' or '#' into chat will set the default channel you type in
- there is a keybind for changing what chat you are typing in (irc/minecraft)
- when messages you send will be sent to irc, the chat bar will be blue.
- pressing the irc/minecraft buttons will set the default channel you type in (which channel messages get sent to when you press enter)
- you can switch between irc/minecraft then to global as a faster way of switching current typing in channel

this mod WILL break the timestamps function of chat tools mod, you can still use chat tools but the timestamps function will just not do anything.
